# Evidence notes

Add **dated** source notes here. Suggested naming convention:

`YYYY-MM-DD_source_topic.md`

Recommended sources include current issuer filings, fund fact sheets,
IRS treaty/W-8BEN materials, SARS guidance, broker tax statements, and
MLP/REIT distribution tax-character notices. The repository intentionally ships
without fabricated citations. The RAG retriever treats this folder as the only
trusted context and returns `UNKNOWN` when it finds no supporting note.
